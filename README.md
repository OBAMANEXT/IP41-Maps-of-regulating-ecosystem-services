# IP-41 Maps of regulating ecosystem services

Species distribution model based maps of seven regulating services for the Finnish marine area.

Forsblom L, Jernberg S, Kuosa H, Kostamo K, Gustafsson C, Virtanen EA (2025) Integrating Regulating Ecosystem Services in Marine Conservation Planning. _Aquatic Conservation: Marine and Freshwater Ecosystems_ 35:e70196. [https://doi.org/10.1002/aqc.70196](https://doi.org/10.1002/aqc.70196)

The species data that support the findings of this study are openly available in Zenodo: [https://doi.org/10.5281/zenodo.13822191](https://doi.org/10.5281/zenodo.13822191)
